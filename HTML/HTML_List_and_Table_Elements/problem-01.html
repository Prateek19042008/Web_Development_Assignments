University Admission Handbook

Admission Overview:

This handbook gives basic information about the admission process, eligibility, required documents, fees and other important details. Students should read all the instructions before applying.

Eligibility:

Students who have completed their required qualifying examination can apply for admission according to the eligibility criteria of the selected course.

Important: Check the course eligibility before submitting the application form.

Application Deadline: Check the official admission portal for the latest date.

Application Process:

  1. Visit the official admission website.
  2. Register using your basic details.
  3. Fill in the application form carefully.
  4. Upload the required documents.
  5. Pay the application fee, if applicable.
  6. Submit the application form.
  7. Keep the application number for future reference.

Required Documents:

  • Class 10 marksheet
  • Class 12 marksheet
  • Transfer Certificate
  • Migration Certificate, if required
  • Valid identity proof
  • Passport-size photographs
  • Category certificate, if applicable

Important Terms:

Eligibility
The conditions a student must satisfy to apply for a course.
Merit List
A list prepared according to the performance or marks of applicants.
Counselling
A process where students receive information about courses and admission.
Scholarship
Financial assistance provided to eligible students.
Registration
The process of entering student details for admission.
